# YOSE'S PROJECT

Proyecto personal Android-first con estética metalcore para visualizar progreso: menos alcohol, más actividad física y una vuelta estructurada al entrenamiento.

## Estado

Vertical slice web en desarrollo: calendario mensual, ficha diaria, registro local con IndexedDB y animación ritual de apertura.

## Stack

- React + TypeScript + Vite
- IndexedDB en preview web
- Capacitor + SQLite previstos para Android
- Kotlin + Jetpack Glance previsto para widgets Android

## Desarrollo local

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
